Secure CFO / T-VER Auditor & TGO Prep Pack

เครื่องมือช่วยตรวจความครบถ้วนของหลักฐานและข้อมูลกิจกรรมจากไฟล์ Excel / Word พร้อมรายงานข้อสังเกตและรายการแก้ไขที่ตรวจสอบย้อนกลับได้

ข้อจำกัดสำคัญ: นี่คือเครื่องมือช่วยคัดกรองเบื้องต้น ไม่ใช่ผู้ทวนสอบที่ได้รับการรับรอง และไม่รับรองความสอดคล้องกับ CFO/T-VER/TGO โดยอัตโนมัติ ค่า EF ต้องตรวจสอบกับฐานข้อมูล/ระเบียบวิธีที่ใช้จริงและเวอร์ชันที่มีผล ณ รอบรายงาน

1. นำเข้าเอกสาร

ยังไม่มีการนำเข้าไฟล์ เครื่องมือจะไม่แทนที่ไฟล์จริงด้วยข้อมูลตัวอย่างเอง

รองรับการประมวลผลในเบราว์เซอร์สำหรับไฟล์ที่เลือกในหน้านี้ แต่ไลบรารีที่โหลดจาก CDN ทำให้เบราว์เซอร์เชื่อมต่ออินเทอร์เน็ตเพื่อดาวน์โหลดโค้ดได้ ห้ามใช้กับข้อมูลลับจนกว่าจะผ่านการตรวจสอบนโยบาย IT/ความปลอดภัยขององค์กร

2. เกณฑ์คัดกรอง

Materiality เป็นค่าที่ผู้ใช้กำหนดเพื่อจัดลำดับความสำคัญเท่านั้น ไม่ใช่การยืนยันว่าเกณฑ์ดังกล่าวตรงตามข้อกำหนดของโครงการ

3. ภาพรวมผลตรวจ

รายการข้อมูลกิจกรรม0
ข้อสังเกตทั้งหมด0
ระดับสูง0
ผลเทียบเฉลยยังไม่ตรวจ
นำเข้าไฟล์ Excel และ/หรือ Word แล้วกดตรวจสอบเพื่อเริ่มต้น

4. ข้อสังเกต / Findings

ผลลัพธ์นี้เป็นการตรวจความครบถ้วนและความผิดปกติเบื้องต้น ไม่ได้คำนวณการปล่อยก๊าซเรือนกระจกจนกว่าจะยืนยันหน่วยและค่า EF ของแต่ละรายการ

ยังไม่มีผลตรวจ

5. เทียบ Answer Key (ไม่บังคับ)

วาง JSON array ที่ระบุ id และค่าที่คาดหวัง เช่น [{"id":"R2","expectedStatus":"PASS"}]. การเทียบจะตรวจค่าตรงกันจริง ไม่ใช่แค่พบ ID ที่เหมือนกัน

ยังไม่ได้เทียบ Answer Key

6. แนวทางแก้ไขและบันทึกการตรวจ

ระบบจะไม่แก้ไฟล์ต้นฉบับหรือเติมค่าตัวเลขที่ไม่มีหลักฐานให้โดยอัตโนมัติ

ยังไม่มีข้อเสนอแก้ไข

7. Sampling / TGO Prep Notes

รายการต่อไปนี้เป็นแนวทางเตรียมงาน ไม่ใช่ sampling plan ที่รับรองทางสถิติหรือแบบฟอร์มทางการของ TGO

  • ยืนยันขอบเขตองค์กร ขอบเขตการดำเนินงาน และช่วงเวลารายงาน
  • ตรวจสอบวิธีการคำนวณ หน่วย และแหล่งอ้างอิงของ emission factor ทุกชุด
  • เชื่อมแต่ละข้อมูลกิจกรรมกับหลักฐานต้นทางที่ตรวจสอบย้อนกลับได้
  • กำหนด sampling ตามความเสี่ยง ความมีสาระสำคัญ ความแปรปรวน และข้อกำหนดของระเบียบวิธีที่ใช้จริง
  • ตรวจสอบแบบฟอร์ม/เกณฑ์ฉบับล่าสุดจาก TGO ก่อนนำส่ง
ความเป็นส่วนตัว: การล้างข้อมูลจะล้าง reference และหน้าจอของแอปเท่าที่ทำได้ แต่ JavaScript ไม่สามารถรับประกันการลบข้อมูลจาก RAM/ระบบปฏิบัติการอย่างปลอดภัยได้ ดาวน์โหลดรายงานแล้วจัดเก็บตามนโยบายองค์กร
